# ポートフォリオ公開サイト

HTML、CSS、JavaScriptを用いて制作するポートフォリオサイトです。

Webサイトの制作に加え、Git・GitHubによるバージョン管理や、GitHub Flowを用いた開発手法の習得を目的としています。

## 公開サイト

**URL：** [https://polyfortrain.github.io/](https://polyfortrain.github.io/)

GitHub Pagesを利用して公開しています。

## 使用技術・開発環境
- フロントエンド ... HTML5、CSS3、JavaScript
- 開発環境 ... Eclipse IDE
- バージョン管理 ... Git / GitHub
- 開発フロー ... GitHub Flow
- ホスティング ... GitHub Pages

## 開発・バージョン管理

開発にはGitHub Flowを採用しています。

機能追加や修正は作業ブランチで行い、Pull Requestによる変更内容の確認を経て`main`ブランチにマージします。

バージョン番号は[Semantic Versioning](https://semver.org/lang/ja/)を参考に管理し、リリース時にはGitタグとGitHub Releasesを利用します。

## 変更履歴・リリース情報

各バージョンの変更履歴は、[Keep a Changelog](https://keepachangelog.com/ja/1.1.0/)を参考に`CHANGELOG.md`で管理しています。

- **[CHANGELOG.md](CHANGELOG.md)** — バージョンごとの変更内容
- **[GitHub Releases](https://github.com/polyfortrain/polyfortrain.github.io/releases)** — リリースノート・Gitタグ・ソースコード
- **[Issues](https://github.com/polyfortrain/polyfortrain.github.io/issues)** — 機能追加・不具合修正などの課題管理
- **[Pull Requests](https://github.com/polyfortrain/polyfortrain.github.io/pulls)** — 変更内容の確認・レビュー

なお、`CHANGELOG.md`の`Unreleased`には、次回リリースに向けた変更内容を記録します。
